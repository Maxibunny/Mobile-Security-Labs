# Словарь основных терминов для защиты

**APK** — установочный пакет Android; `notes` и `client` собираются в разные APK.

**Application / Activity** — Application живёт на протяжении процесса и хранит общие зависимости; Activity — экран и обработчик внешних Intent.

**ADB (Android Debug Bridge)** — утилита разработчика для связи ПК с эмулятором/телефоном. `adb shell` выполняет команды с UID оболочки, **не** под подписью вашего клиента.

**AndroidManifest.xml / merged manifest** — объявления компонентов, фильтров Intent и разрешений; merged — конечный XML после слияния с библиотеками, именно он попадает в APK.

**`android:exported`** — может ли системный компонент вызываться другим приложением. `true` может быть безопасным при дополнительном `signature`-разрешении.

**Intent** — сообщение «что сделать и кому». `ACTION_VIEW` означает просмотр; `ACTION_SEND` — поделиться. Явный Intent задаёт конкретный компонент; неявный выбирается через фильтры Android.

**Deep link** — URI-ссылка, открывающая экран приложения. Здесь `notes://note/1`. `https App Link` отличается тем, что домен должен быть проверен.

**URI / scheme / host / path** — адрес ресурса: `notes://note/1` имеет scheme=`notes`, host=`note`, path=`/1`; `content://.../notes` адресует ContentProvider.

**`encodedPath`** — путь в его кодированном виде, без неоднозначной автоматической декодировки `%31` и других вариантов.

**ContentProvider / ContentResolver** — серверная (Notes) и клиентская (другое APK) части доступа к данным Android. Взаимодействие между процессами идёт через Binder.

**Binder** — системный механизм межпроцессных вызовов Android с проверкой вызывающего UID/разрешений.

**Authority** — глобально уникальное имя ContentProvider, например `edu.androidsec.notes.provider`.

**Manifest permission** — системное ограничение вызовов, выполняемое Android до передачи запроса компоненту.

**`signature` permission** — разрешение, доступное приложениям с требуемой цифровой подписью APK; объявление `<uses-permission>` не обходит проверку.

**Digital signature / keystore** — сертификат, которым подписывают APK, и хранилище ключа. Одна машина и один debug.keystore обычно означают одинаковую debug-подпись обоих модулей.

**FileProvider** — библиотечный ContentProvider, который даёт ограниченный `content://` доступ к файлам приватного каталога через URI-гранты.

**`FLAG_GRANT_READ_URI_PERMISSION`** — временное разрешение выбранному получателю читать URI; не раскрывает полный файловый каталог.

**PendingIntent** — право отложенно выполнить заранее подготовленный Intent с полномочиями приложения-создателя; например при нажатии на уведомление.

**`FLAG_IMMUTABLE`** — запрет получателю PendingIntent редактировать его содержимое. **`FLAG_UPDATE_CURRENT`** — владелец обновляет ранее созданную запись.

**BroadcastReceiver** — компонент, принимающий сообщения/broadcast. При `exported=false` недоступен чужому приложению напрямую.

**POST_NOTIFICATIONS** — runtime-разрешение на показ уведомлений на Android 13+; требуется объяснить пользователю и выдержать отказ.

**Photo Picker** — системный интерфейс выбора конкретной фотографии без разрешения на всю медиатеку.

**Room / SQLite / Entity / DAO** — Room предоставляет объектный интерфейс к SQLite; `Entity` описывает таблицу, `DAO` — SQL-операции.

**Repository / ViewModel / Compose** — Repository изолирует операции с данными; ViewModel хранит состояние UI и операции; Compose рисует интерфейс по StateFlow.

**`suspend` / Coroutine / Job / Scope** — асинхронные операции Kotlin; `Job` можно отменить, Scope задаёт время жизни, `delay` не блокирует UI.

**Flow / StateFlow / Channel** — Flow отдаёт последовательные обновления, StateFlow хранит текущее значение, Channel удобен для одноразовых событий вроде Toast.

**`SecurityException`** — ошибка отказа системы безопасности Android. Ожидается при чужом запросе к защищённому ContentProvider.

**`UnsupportedOperationException`** — метод существует, но операция намеренно запрещена, например `insert` в read-only TitlesProvider.

**`PASS=18 FAIL=0`** — результат конкретного запуска bash-скрипта с 18 проверками. Он подтверждает только то, что этот скрипт действительно протестировал, не заменяет ручные сценарии.

**Gradle / Kotlin JVM target / AGP** — инструменты сборки и настройки целевого Java-байткода. Для проекта нужны согласованные Java/Kotlin 17, AGP 8.13 и Android SDK 36.
