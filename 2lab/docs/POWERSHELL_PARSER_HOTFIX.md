# Исправление PowerShell ParserError (21.10.2026)

В предыдущем архиве в scripts/auto_run_windows.ps1 было четыре неверных
включения переменной перед двоеточием, например `"$Name: OK"`.
PowerShell 5.1 воспринимает `$Name:` как имя переменной с областью/диском,
из-за чего файл вообще не запускался.

Исправлены строки 91, 101, 102, 103: `$Name:` -> `${Name}:`.
Логика установки, сборки и `scripts/check.sh` не изменена.

Инструкция:
  1. Если проект уже открыт и собран, удобнее заменить только
     2lab/scripts/auto_run_windows.ps1 отдельным файлом из ответа.
  2. Дважды нажать START_LAB2.cmd.
  3. Если скрипт завершится с ошибкой, прислать logs/auto-.../summary.txt.

Проверено: четыре проблемных шаблона исправлены; ZIP целый;
статическая проверка исходников проходит.
